# Benokee App - Interactieve Demo

Een volledig interactieve HTML demo die alle features van de Benokee app toont.

## 🚀 Live Demo

De demo is direct te gebruiken en makkelijk deelbaar:

### Opties om te delen:

1. **GitHub Pages** (aanbevolen)
   - Upload `index.html` naar een GitHub repository
   - Activeer GitHub Pages in repository settings
   - Deel de link: `https://[username].github.io/[repo]/demo/`

2. **Netlify/Vercel** (gratis hosting)
   - Sleep de `demo` folder naar Netlify Drop
   - Of gebruik Git integration
   - Automatische HTTPS en CDN

3. **Direct delen**
   - Deel het HTML bestand direct
   - Of gebruik een gratis hosting service zoals:
     - [CodePen](https://codepen.io)
     - [JSFiddle](https://jsfiddle.net)
     - [Replit](https://replit.com)

4. **QR Code**
   - Genereer een QR code van de demo URL
   - Perfect voor presentaties en flyers

## 📱 Features in de Demo

### ✅ Volledige App Flow
- **Taalselectie** - Nederlands/Engels met vlag knoppen

## 🎮 Gebruik

### Interactief
1. Open `index.html` in je browser
2. Klik door alle schermen
3. Test alle functionaliteit

### Auto Demo
- Klik op **"▶️ Auto Demo"** voor automatische presentatie
- Klik op **"🔄 Reset"** om terug te gaan naar begin

### Delen
- Klik op **"🔗 Deel Demo"** knop rechtsboven
- Kopieer de link of deel direct
